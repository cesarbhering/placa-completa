O que estamos tentando fazer01

Construir a ferramenta gratuita mais útil do Brasil para consultar veículos por placa, monetizando via SEO orgânico, tráfego de IA e (em breve) mídia paga. O produto tem que ser rápido, honesto e substantivo — não é feed de conteúdo raso pra ranquear no Google, é uma consulta real com dados úteis.

Três frentes rodam em paralelo:

  • Produto: web (Nuxt 3 hospedado via Coolify) + app Android (TWA embarcada). Toda experiência real vive no mesmo domínio; o app é um wrapper. Fluxo básico: digita placa, recebe marca/modelo/ano/cor/FIPE/situação, seja na tela (app/PWA) ou no e-mail (web).
  • Distribuição: SEO orgânico como canal principal, complementado por conteúdo editorial (série mensal IBV Auto), Twitter (@PlacaCompleta), press release para pequenos veículos, e agora integração com Google Ads para experimentos pagos.
  • Infraestrutura: tudo próprio, servido de VPS Contabo com Coolify, deploy contínuo via GitHub webhook, e uma coleção de helpers CLI (pc-mail, pc-x-post, pc-ads-auth, pc-seo-audit-reminder) para automatizar operações repetitivas sem virar shell script pool.

  • CTR médio GSC subindo para 2,5%+ com ajuda de rich results (hoje: zero rich results detectados, meta 20+).
  • Cliques GSC mensais no patamar 300+ (hoje ~110/mês).
  • Sessões AI acima de 400/mês (hoje ~570 combinando AI Assistant + Unassigned).
  • Primeira aparição em top 20 para alguma head query (hoje: fora do top 100 nas grandes como "consulta placa" 450k vol/mês).

Sinais de que a estratégia está funcionando

O crescimento de junho já valida a tese: quando o site sobe schema + conteúdo único, tanto Google quanto ChatGPT respondem. A próxima ferradura é fazer o mesmo tipo de investimento nas queries head — não vamos ranquear consulta placa em 3 meses, mas dá para atacar a cauda intermediária (5–50k vol) onde a competição é menor e a intenção comercial ainda é alta.
