## Procedimento

1. GSC → barra de busca no TOPO da página (não a lateral)
2. Cola a URL completa
3. Aguarda ~5-10s carregar "Inspecionar URL"
4. Clica **"Solicitar indexação"**
5. Espera ~30s pelo teste rápido
6. Mensagem "URL na fila de indexação prioritária" = sucesso
7. Próxima URL

Marca [x] no checkbox aqui pra trackear. Quando todas estiverem marcadas, indexação está requisitada para todas as páginas novas.
